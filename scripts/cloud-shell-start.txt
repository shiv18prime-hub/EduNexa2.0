EduNexa Spark foundation setup — student-result-pro

Run this command in this Cloud Shell terminal:

  bash scripts/activate-project.sh --spark

Google sign-in/authorization happens here in your own Google environment.
Enter any authorization code in this terminal only; never send credentials to chat.
When asked for an admin email, enter your existing EduNexa Google-login email.
The script validates that account, deploys only Firestore rules/indexes, authorizes
the existing web domain and grants that selected account the admin role.
It does not deploy Functions or Storage, or change billing. No Blaze upgrade is
needed for this foundation setup. Sign out/sign in after the admin role is granted.
The current Android/web source includes Spark-native dashboards, personal result
history, school membership workflows and guarded school result/attendance/notice
publishing. Update the client and deploy the branch Firestore rules before using
those features. This setup does not enable callable timed tests, chat, Pro/coupons,
marksheet services or cloud photo uploads; those still require Cloud Functions or
Storage. See the feature-status table in DEPLOYMENT.md. This is not full app activation.
